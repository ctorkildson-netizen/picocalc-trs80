Keys for a game: choose one with F6 (Shift-F1) in trs80.

Each line is "PicoCalc key = Model I key". # starts a comment.

PicoCalc keys: a character, or LEFT RIGHT UP DOWN SPACE ENTER TAB
BACKSPACE DEL HOME ESC.

Model I keys: @ A-Z 0-9 : ; , - . / or ENTER CLEAR BREAK UP DOWN LEFT
RIGHT SPACE SHIFT. (Not the shifted symbols: ! " # and so on are SHIFT
with another key.)

Keys a layout doesn't name work as usual. A file with a wrong line isn't
used at all, and trs80 says which line.
